# Gradify

A Go package to make colorful gradiant terminal output.

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
[![Language](https://img.shields.io/badge/Go-00ADD8?logo=go&logoColor=white)](https://go.dev/)
## Features

- Hex to RGB conversion
- Multi-color linear interpolation
- Custom gradiant presets
- Truecolor ANSI support

## Installation

```bash
go get github.com/yourpovv/gradify
```
